# Web Services Practical Collection
Base implementations for the selected practical patterns. Each practical folder is a standalone Eclipse-importable project where applicable and contains its own ZIP archive.

Java projects use Eclipse project metadata. Maven projects include `pom.xml`; plain Java projects include `.project` and `.classpath`. JavaScript practicals are run with Node.js.

These are starter implementations, not yet fully verified in Eclipse/Postman/external servers. Test each project before relying on it in an exam.
